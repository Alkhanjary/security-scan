Three scan modes, one report

Point it at a folder, a URL, or a host/CIDR — it figures out what to do.

Code scan

Hardcoded secrets and API keys, dangerous calls (eval, exec, os.system, shell=True), SQL injection patterns, XSS sinks, insecure deserialization, weak crypto, and infra misconfiguration.

Web scan

Missing security headers (HSTS, CSP, X-Frame-Options), insecure cookie flags, TLS certificate/protocol issues, reflected XSS and error-based SQL injection via a lightweight same-origin crawl.

Network scan

Open ports, risky exposed services (FTP, Telnet, RDP, VNC) and outdated-looking service banners across a single host or a whole /24 subnet.

AI verification

Every finding gets a true/false-positive verdict, plus a scan for anything the deterministic rules missed, and a plain-language risk summary with fixes. The regex/port scan always stays the source of truth for pass/fail.

How it works

1

Point it at a target

A folder, a live URL, or a host/CIDR — auto-detected from what you give it.

2

Deterministic scan runs

Fast, offline regex/port checks — no network calls, nothing leaves your machine.

3

Optional AI verification

Each finding is checked for true/false positives and given a fix recommendation.

4

Shareable report

Markdown, HTML, JSON or CSV — export from the CLI or the scanner dashboard.

Quick start

No arguments scans the current directory for hardcoded secrets and risky code patterns.

Just run it
py scanner.py
Point it at anything
py scanner.py https://example.com     # web scan
py scanner.py 10.0.0.5                # network scan
py scanner.py ./some-repo             # code scan of a folder
With AI verification
py scanner.py --all --url https://example.com --net-target 127.0.0.1 --ai --report report.md
